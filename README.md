# ProjetoX Backend

A JavaScript-based backend project for ProjetoX.

## About

This repository contains the backend implementation for the ProjetoX application, written entirely in JavaScript.

## Tech Stack

- **Language**: JavaScript
- **Type**: Backend

## Getting Started

### Prerequisites

- Node.js (v14 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/pedropestana00/projetoX-back.git
```

2. Navigate to the project directory:
```bash
cd projetoX-back
```

3. Install dependencies:
```bash
npm install
```

### Running the Project

```bash
npm start
```
